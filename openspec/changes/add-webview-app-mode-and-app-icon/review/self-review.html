Residual Risk

  2. macOS Dock/Application Switcher smoke needs a human-visible run.
  3. The macOS extension runtime currently has one native WebView slot; process-wide aggregation across multiple extension runtimes keyed by (appId, sessionId, windowId) remains open.

Decision

The available implementation slice is internally consistent and automated gates are green. Keep the OpenSpec change active until the platform GUI and multi-runtime Darwin evidence is complete; do not archive it as fully complete yet.
