add-tray-primary-event self review

primaryEvent is an additive role on a plain menu item. The public event remains menuClick, while the tray-icon backend owns native primary gesture routing.

Check Evidence Verdict
Protocol contract pnpm --filter @opentray/spec test and cargo test -p opentray-spec prove primaryEvent is optional, camelCase on the wire, and still pairs with normal menuClick event frames. Pass
Kernel boundary cargo test -p opentray-core and the focused core grep show that core preserves the role as data and has no Windows/macOS/Linux primary-click branch. Pass
Backend routing cargo test -p opentray-backend-tray-icon covers enabled primary routes, disabled primary suppression, duplicate first-enabled behavior, nested menu routes, and runtime primary ingress delegation. Pass
Broker ingress cargo check -p opentray-bin compiles the native tray-icon event-loop ingress that routes supported primary activation through backend and kernel ownership. Pass
