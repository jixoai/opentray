Local Broker Daemon

The OpenTray package now exposes an explicit daemon lifecycle command surface with version-scoped runtime state.

Command

opentray daemon start|stop|restart

The corrected spelling is canonical.

Runtime

~/.opentray/<version>/runtime/

Pid, lock, and ready metadata stay inside the current version.

Endpoint

opentray-p1.sock

The bound endpoint reuses package/protocol version identity.
