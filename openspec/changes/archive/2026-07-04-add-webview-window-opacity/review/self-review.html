Window Opacity Review

Ontology

style.opacity    -> whole native-window alpha
style.background -> native backing/material/blur
style.platform.* -> substrate-specific appearance

Evidence

  • pnpm --filter @opentray/ext-webview test: passed, 34 tests.
  • pnpm --filter @opentray/ext-webview typecheck: passed.
  • cargo test -p opentray-ext-webview: passed, 54 tests.
  • cargo check -p opentray-ext-webview --target x86_64-pc-windows-msvc: passed with rustup cargo/rustc.
  • pnpm --filter @opentray/ext-webview build: passed.
  • bun run openspec:vision -- validate add-webview-window-opacity: passed.
  • bun run openspec:vision -- check add-webview-window-opacity: passed.
  • git diff --check: passed.

Documentation

  • README, examples, and the WebView control demo document and expose style.opacity as whole-window shell alpha.
  • OpenSpec records opacity as separate from style.background and owned by the WebView extension atom.
  • WebView pattern guidance scopes the Windows WS_EX_LAYERED warning to background and white-block repair; opacity is the explicit exception.

Decision

No review loop required. The change is additive and remains inside the WebView extension atom.
