Navigator Window API Review

Status: implementation and verification passed. This review covers the navigator bridge itself, not the separate registry-release parity issue.

Public Surface

navigator.window is the promoted API and navigator.opentrayWindow is the prefixed fallback, both backed by the same object.

Tauri-Style Layering

Pages see invoke, listen, and once, while the extension keeps callback ids and Wry IPC private.

Global Override Gate

window.close(), window.moveTo(), and window.resizeTo() remain untouched unless bindWindowGlobals is explicitly enabled.

Capability Honesty

transparent and backgroundEffect reject with typed unsupported errors instead of pretending macOS support exists.

Runtime Split

The release binary check keeps WebKit.framework on the WebView dylib, not on the main opentray binary.
