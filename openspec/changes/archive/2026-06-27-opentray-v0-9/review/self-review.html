OpenTray v0.9 Tray-First Reset Self Review

Architecture Verdict

The implementation removes public Space/Surface creation, moves protocol routing to app/tray identity, removes tray title mutation, and updates core/backend/extension host atoms around app-owned tray projection. Rust protocol and tray-icon projection now accept the responsive icon candidate map and preserve text-only absence when the native backend cannot render it.

The implementation also adds a bundler-neutral packaging contract, the first Vite adapter, and the first Node runtime-binding distribution slice. Platform runtime packages now stage runtime/opentray_runtime.node from opentray-runtime-node instead of publishing a standalone broker executable. Remaining public Lease aliases, health fields, and extension ABI cleanup symbols were destructively renamed to Session vocabulary.

The binding now also owns a headless direct protocol/session runtime. It can handle init, resolve-default-app, and create-tray without a local broker socket. The default visible createTray() path still uses transitional local-broker transport until the binding owns the native event-loop-backed tray host.
