# @opentray/ext-webview-windows-x64

Windows x64 native dynamic library package for `@opentray/ext-webview`.

This package is installed as an optional platform artifact. Source control does not commit the generated dynamic library; CI stages it into `bin/` before npm publish.

Current maturity: `alpha` for distribution, contract shape, and the first visible WebView2-backed runtime. Common lifecycle, page bridge commands, background material/corner preferences, and native icon projection are supported.
