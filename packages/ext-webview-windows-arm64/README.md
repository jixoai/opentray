# @opentray/ext-webview-windows-arm64

Windows arm64 native dynamic library package for `@opentray/ext-webview`.

This package is installed as an optional platform artifact. Source control does not commit the generated dynamic library; CI stages it into `bin/` before npm publish.

Current maturity: `alpha` for distribution and contract shape. The package may install correctly while the visible WebView runtime still returns typed unsupported results until Windows runtime support lands.
