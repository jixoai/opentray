Hotfix: applications generated by 0.27.3 crashed on launch (broker SIGABRT in create-webview). The macOS context-menu isa-swizzle (runtime subclass swap on the WKWebView instance) is disabled — CI-binary A/B isolated the crash to exactly that create-webview-time class swap. Windows menu suppression (AreDefaultContextMenusEnabled) and the `browser.contextMenu` option surface stay; macOS suppression moves to the trusted-page layer in a follow-up.
