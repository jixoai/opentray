## Friction recorded (operational lessons, not product defects)

1. The first walkthrough "hang" was a dead evidence server: a background
   server started with `&` inside a sandboxed tool-call shell dies with the
   shell. Symptom cascade: honest `failed` loadState frames (connection
   refused) + no HTTP entries. Fix: persistent background task.
2. `lsof` ESTABLISHED snapshots are NOT load-liveness evidence (short-lived
   connections close before sampling). Carrier breadcrumb prints were the
   decisive instrument.
3. `packages/ext-webview/dist` was stale (built 00:45, pre-8.2): the packed
   tarball's facade had no `onLoadState` and the generated app failed at
   `content.onLoadState is not a function`. Rebuilt the dist + repacked —
   publish-chain note: 8.2/8.3 changed src without rebuilding dist; the
   release pipeline rebuilds it, but local tarball walkthroughs must too.
